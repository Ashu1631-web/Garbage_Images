# ♻️ Waste Classification AI

AI-powered garbage classification web app using Deep Learning.

## 🚀 Features

- 🔐 Login System
- 📸 Upload + Camera Detection
- 🧠 AI Prediction (model.h5)
- 📊 10+ Analytics Charts
- 📂 History Tracking
- 📥 CSV Download
- 🎨 Modern UI (Dark + Glass)
- 🌍 Project Overview Page

## 🧠 Model

- MobileNetV2
- Input: 160x160
- Classes:
  - cardboard
  - glass
  - metal
  - paper
  - plastic
  - trash
