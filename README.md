# ♻️ RecycleVision - Garbage Image Classification using Deep Learning

## 🚀 Overview
RecycleVision is a Deep Learning-based Computer Vision project that classifies garbage images into categories like plastic, metal, glass, paper, and organic waste. The system helps automate waste segregation and supports smart recycling solutions.

---

## 🎯 Problem Statement
Manual waste segregation is inefficient and prone to errors. This project builds an AI-powered solution to classify waste images and assist in automated recycling.

---

## 💡 Key Features
- Image classification using CNN & Transfer Learning
- Supports multiple waste categories
- Real-time predictions via Streamlit app
- Confidence score display
- Clean and interactive UI

---

## 🧠 Tech Stack
- Python
- TensorFlow / Keras
- CNN (Convolutional Neural Networks)
- Transfer Learning (MobileNetV2, ResNet50)
- Streamlit
- OpenCV / PIL

---

## 📊 Dataset
- Garbage Classification Dataset (Kaggle)
- Classes:
  - Plastic
  - Metal
  - Glass
  - Paper
  - Cardboard
  - Organic

---

## ⚙️ Workflow

1. Data Collection
2. Data Preprocessing
   - Resizing (224x224)
   - Normalization
   - Augmentation
3. Model Training
4. Model Evaluation
5. Streamlit Deployment

---

## 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

---

## 🖥️ Streamlit App Features
- Upload garbage image
- Predict category
- Show confidence score
- Visual insights & charts
